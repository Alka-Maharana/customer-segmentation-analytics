# Customer Segmentation and Behavioral Analytics

## Project Overview
This project analyzes retail transaction data to understand customer purchasing behavior and identify distinct customer segments using RFM (Recency, Frequency, Monetary) analysis.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Google Colab

## Methodology
- Cleaned transaction data and removed records with missing customer IDs and invalid quantities or prices.
- Calculated customer-level recency, purchase frequency, and total spending.
- Segmented customers using RFM scores.
- Visualized customer distribution and revenue contribution across segments.
- Developed business recommendations based on observed purchasing patterns.

## Dataset
UCI Machine Learning Repository — [Online Retail Dataset](https://archive.ics.uci.edu/dataset/352/online+retail).

## How to Run
Open `Customer_Segmentation_Analytics.ipynb` in Google Colab and run the cells from top to bottom. The notebook downloads the dataset directly from the source.

## Disclaimer
This is an educational retail analytics project. The results are based on historical retail transactions and do not represent a validated banking customer or credit-risk model.
